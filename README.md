# Buscá y Encontrá

Juego de buscar y encontrar para chicos, hecho con los libros ilustrados de casa.

- `index.html`: la app completa (los datos de libros, páginas y objetos están en `const BOOKS=` dentro del script).
- `img/`: las páginas en tamaño grande.
- `th/`: miniaturas y tapas.

## Publicar en GitHub Pages
1. Subí todo el contenido de esta carpeta a un repositorio.
2. En el repo: Settings → Pages → Source: *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
3. En un par de minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

El progreso (estrellas) se guarda en cada dispositivo, en el navegador.
